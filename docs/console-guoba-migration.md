# 控制台逐批替代锅巴配置入口

2026-10-12 第一批：对话设置。

## 第一批交付

控制台 `#/conversation` 分为触发与私聊、访问权限、上下文与路由、任务模型、回复方式。`enabled` 仅关闭 AI 对话，不关闭骰子、搬运或群管；私聊白名单为空时仅主人可聊。任务模型可单独配置，未完整配置时沿用既有回退顺序。主要思考档位仍在 AI 模型页。

字段声明由 `src/modules/config/domain/schemas/shared/` 维护，`models/configSchemas/` 提供独立导出。第一批包含 basic、permission、aiCore、reasoning 和触发模式字段。初次迁移时保留的锅巴重复入口已在 2026-10-16 清理；配置值继续使用同一份 `config/message.yaml`。

配置保存仅提交变更字段，保留无关设置、注释和凭据，使用 revision 检测冲突。密码保持、替换和清除有不同语义。保存不自动重启机器人服务；近期上下文的数量和保留时间需要重启让管道完整生效，其余第一批字段按热更新后新请求生效。

修复聊天共享 MessageManager 的历史上限热更新属性；修复前端 Select 字段校验缺失，防止选了有效值仍无法保存。校准短闲聊额度与三段文字额度，让默认配置能通过字段校验。

## 2026-10-16 群管理交付

新增 `#/group-admin`，与群聊列表和详情互通。默认策略与单群配置均提供入群验证、广告与刷屏处理、欢迎与退群通知；本群通知 QQ 与全局通知 QQ 合并。共享声明位于 `src/modules/config/domain/schemas/shared/`，群管配置由控制台页面维护。

旧 `groupGuard`、`groupModeration`、`groupNotice` 配置继续作为默认值和总开关，旧启用名单、通知模板及通知名单保持兼容。单群稀疏覆盖写入 `groupAdmin.overrides`；支持逐字段自定义、恢复默认，以及保留启用状态的整群恢复。恢复旧配置时只清理当前群的对应字段，兼容群号空格、旧群号别名和重复旧表单记录。

接口使用必填 revision 和文件级冲突检测，保存只更新当前群的 YAML 节点。配置在后续群事件读取；进行中的验证保留题目与截止时间，关闭后不再执行超时处理。已完成本地 HTTP、实际群管运行逻辑、前端和构建产物的桌面/手机浏览器验证；尚未部署，公网联调留在发布验收中。

## 2026-10-16 已覆盖入口清理

按控制台页面实际可编辑、校验、保存的字段撤除锅巴重复入口；配置数据、运行功能和未覆盖设置保留。

| 原锅巴模块 | 清理范围 | 控制台入口 |
| --- | --- | --- |
| basic、permission | 全部基础和权限设置 | `#/conversation` |
| aiModels | 全部 10 组模型渠道及连通性测试按钮 | `#/ai` |
| persona | 默认人设、回复微雕、表达学习、用户和群画像 | `#/persona` |
| messagePipeline | 管道、平台授权和健康报告 | `#/pipeline` |
| groupGuard、groupNotice | 入群验证、广告与刷屏、通知规则 | `#/group-admin` 的默认策略和单群配置 |
| aiCore | 39 个已覆盖字段，保留 `systemContent` | `#/conversation` 和 `#/ai` 的思考程度 |
| tracking | `chatTriggerMode` 及其余 55 个追踪字段 | `#/conversation` 的对话配置与对话追踪 |
| dice | 11 个骰子基础字段 | `#/commands` 的骰子基础 |
| memory | 35 个唯一字段（去重 12 条重复声明） | `#/semantic` 的记忆策略 |

`systemContent` 是自定义补充提示，控制台尚无编辑入口，继续在锅巴单独提供。归档、知识、情绪、表达、表情运行策略、语音、工具凭据及其余娱乐模块基础设置继续留在锅巴。骰子、追踪与记忆策略已在同日后续迁移中补齐原锅巴声明的全部编辑项；命令文案、资产和记忆运营操作保留。

删除已迁移模块的 9 组锅巴 schema 文件及旧 JS 导出（含原本未单独注册的 reasoning、riskControl）。人设、管道与风控声明迁到 shared，控制台和验证脚本改用独立路径。剩余锅巴读取仅投影已注册字段，保存仅接受这些精确扁平字段；旧页面提交已迁移字段、父对象或混合载荷会整次拒绝，提示刷新并到控制台修改，不会部分写入。模型测试 action 同步移除。

这次清理不迁移或删除实例配置，不触发服务重启。本地后端定向 85 项、前端 48 项和浏览器 108 项检查通过，后端及测试类型检查、前后端构建、模块边界与迁移登记校验通过。浏览器覆盖 1440/320 px 和深浅主题，使用本地假 API；剩余锅巴读写限制使用真实临时 YAML 仓库验证。尚未提交、推送或部署，公网联调属于发布验收。
