# 群聊互动最小闭环实施

2026-10-14，基于 `de03521`，已完成本地代码与离线验证。

这批改动让当前话语、回应对象、可读证据、媒体缺口与本机器人上句进入同一条回复链。它为模型提供更可靠的语境，并减少出口把接梗改成严肃说明的情况；真实聊天质量仍需使用实际模型对照评估。

## 已实现

- 新增 `TurnInteractionContext`，包含原始正文、互动线索、说话人、回应对象、证据及可靠的上句来源。规则只提供保守线索，当前明确任务优先于玩笑。
- `chatTurn → turnPromptComposer → finalReply` 共用该上下文。闲聊与任务档都保留 `interaction` 层，不再把当前正文和时间、身份、引用前缀混在一起判口吻。
- 图片、视频及其他素材链接只算引用，不冒充 OCR 或已经看过的内容。现有识图/视频工具返回后更新证据，在既有续轮中重新提供互动线索与口吻，保留原有人格。
- 工具证据按调用 ID 更新。图 A 成功、图 B 失败时仍保留 A 的证据；读取状态使用既有工具结果分类，空结果及未找到不算可读。
- 最终守卫、叙事判断、情节摘要、跟踪与增强系统使用独立正文。明确技术问题保持认真，具有明确玩笑线索的技术词不会单独触发严肃说明。
- 续聊记录按群/私聊、用户、机器人账号隔离，并校验来源。引用、转发里的第一人称不自动成为本机器人经历。明确叫机器人评价别人时，引用者仍是素材来源。
- 仍以确认发送回执为准登记回复、续聊与学习。诊断只增加互动类型和证据数量，不额外保存正文。

## 脱敏回放

场景数据在 `tests/fixtures/interactionReplayScenarios.json`，不含原群用户账号、私有转发全文或有效媒体签名链接。

| 场景 | 验证重点 |
| --- | --- |
| 本地模型图片玩笑 | 识别互动线索，图片 URL 不算识图事实 |
| 运行十分钟的变体 | 保留新时长，不使用固定“两小时/硅脂”模板 |
| 认真排查散热故障 | 当前认真请求覆盖旧玩笑 |
| 视频尚未读取 | 保留已知文字，只对缺失素材表示不确定 |
| 普通拒绝 | 允许短答，不补真人身体或生活经历 |
| 改图交付与第二句 | 依据已确认上轮结果；第二句具体反馈邀请完整保留 |

`tests/interactionReplay.test.js` 使用真实回合编排、素材解析、提示组装、系统提示、输出管线与最终回复。模型响应、平台发送和存储使用假依赖。与纯域测试合计 23 项，另有实际工具感知续轮、口吻优先级和续聊隔离回归。

离线桩回复只能证明输入、证据、提示传递、口吻边界和发送登记正确，不能证明模型会生成更机灵的句子，也不能自动评判第二句的语义质量。

## 后续评估

用同一模型、相同参数和相同输入比较旧版与新版：能否接住具体话题、是否有自己的反应、是否准确区分素材缺口、第二句是否带来新动作，以及认真问题是否仍然可靠。不要把长度、禁词命中或固定桩答案作为“像人”的评分。

这批规则仍是保守提示，不保证识别所有隐喻和复杂关系。没有来源的旧续聊记录不会迁移为本机器人的立场，新记录从下一次确认投递开始累积。长期关系状态、广泛人设/情节缓存治理及真实模型评测不在这批实现内。
