# 人设快照与经历来源实施记录（2026-10-15）

本轮完成在线聊天回合的人设固定，以及反馈、短期续聊、情节和最近机器人发言的来源隔离。已在本地构建和验收，尚未部署；没有调用真实模型、发送 QQ 测试消息或写生产记忆。原优化清单仍有未完成项，不能把本轮结果解释为聊天自然度已经提升。

## 实际改动

主回合在首次异步工作前解析库内稳定人格 ID，生成深复制、冻结的 `PersonaSnapshot`，包含 bot、人格 ID、内容版本、完整人格、系统提示及输出 guard。内容版本同时覆盖人格字段、系统提示和 guard，同 ID 编辑也会成为不同版本。

Gate 在等待历史记录前捕获同一份人格；只有实际继续回复且 debounce 成功时，才将它交给正式回合。主提示、语气、情绪人格输入、路由配置、最终文字、卡面、语音、进度 guard、发送归档和本轮记忆来源沿用快照。下一独立回合重新解析配置。未配置 guard 也是快照的一部分，不能继承处理中刚加载的 guard。

真实出站事件通过原型继承群、用户和 bot 身份。已修复最终回复、反馈和卡面包装中对象展开丢身份的问题，并在包装事件自身固定快照，防止原事件被复用时改变本轮人格。三个进度出口使用真实 guard 回归，确认账号昵称不会抢占当前人格姓名。

反馈提示缓存、最近已投递回复、持久反馈摘要及显式反馈的语义检索按 bot／人格 ID／版本分区，新反馈立即使对应缓存失效。短期续聊使用独立版本命名空间并校验来源，旧轮晚到的写入不会覆盖新人格。旧无来源反馈和续聊数据保留，但不自动注入具体人格。

情节继续共享群友的公开原话，回复额外保存来源。召回与提示构造都校验当前读者：只有 bot、人格 ID、版本全部相同，才使用“你回了／你当时回”。其他人格的回复明确标明来源；旧无来源记录保留公开正文，不冒认自身经历。最近消息存读两端验证 `source: send` 和 sender 对应关系，只持久化四个身份字段；主模型历史中只有同源发言使用 assistant 角色。

长期结构化事实的 `heardFrom` 仍主要是显示名，不能精确区分同名 bot 或同 bot 的不同人格版本。公共群主线、对方画像和公开表达继续共享；`auto_evolution` 仍全局学习回复节奏，只有显式 `master_feedback` 的跨人格语义旁路已封闭。独立消息档案和跨重启工具任务恢复也未持久化完整人格快照。本轮不宣称全类型记忆或所有自学习都完成来源升级。

版本变化会启用新的反馈／续聊作用域，旧数据仍在原位置保留；这会使改设定后的第一轮不继续使用旧版本的自我经历。未对无来源旧记录进行猜测式归属或破坏性迁移。
